# Treasury resolution book

The canonical Amaru treasury **resolution book** is published as a repo
asset at a stable HTTPS URL:

- [`amaru-treasury-book.ttl`](assets/amaru-treasury-book.ttl) —
  `https://lambdasistemi.github.io/amaru-treasury-tx/assets/amaru-treasury-book.ttl`

## What it is

A Turtle overlay generated by the `book-export` verb from the vendored
canonical journal metadata (`journal/2026/metadata.json`). For every
registered treasury scope it names:

- the scope owner key hash (`overlay:Owner`),
- the treasury address (`overlay:Address`, with its bech32), and
- the treasury / permissions / registry script hashes
  (`overlay:CardanoScript`),

each with a human `rdfs:label` (e.g. `"network_compliance treasury"`).

## Purpose

Import the book URL into the
[Cardano Swiss Knife Library](https://lambdasistemi.github.io/cardano-swiss-knife/library/)
via its **Book URL** input. The Library then resolves the raw Cardano
identifiers in Amaru treasury transactions to named scopes and roles,
live from the published location — no operator-local file to hand around.

## Provenance and fidelity

The book is a faithful export of the upstream `pragma-org/amaru-treasury`
journal (the pinned commit and sha256 are recorded in the repo's
[`journal/README.md`](https://github.com/lambdasistemi/amaru-treasury-tx/blob/main/journal/README.md)).
It reproduces the journal verbatim, including the known `contingency`
`registry_script.hash` typo; it is a resolution aid, not an authority on
on-chain script hashes. A CI drift check
(`nix build .#checks.x86_64-linux.book`) fails closed if the committed,
published book ever diverges from regeneration.
